# 畫面設計：匿名聊天室

> 這份文件記錄 `/design` 階段決定的視覺風格與畫面細節，對應 `docs/architecture.md` 第 7 節「畫面清單」。做前端（HTML/CSS/JS）時依照這份文件的顏色、字體、間距、元素行為來實作。
>
> 互動原型（可以實際點點看）：[匿名聊天室畫面設計](https://claude.ai/artifact/UQSEoEyvGg3edF6M9k96g6)（私人連結，只有建立者能打開；若要分享給別人看，要先到該頁面的 Share 選單設定）。

---

## 1. 風格方向

**活潑可愛**：暖色系底色、圓角卡片、鮮豔但不刺眼的色塊、彩色字母頭像。不使用 emoji 當圖示（一律用手繪線條風格的 SVG icon），避免常見的「AI 感」設計（漸層洗版、左邊條卡片、Inter/Roboto 字體）。

## 2. 色票

| 用途 | 色碼 | 說明 |
|---|---|---|
| 背景（奶油色） | `#FFF8F0` | 整個網站的底色 |
| 背景漸層深色 | `#FFE9D6` | 輸入代號畫面的漸層底色 |
| 卡片/輸入框底色 | `#FFFFFF` | 白色卡片、訊息泡泡（別人）、輸入框底 |
| 主色（珊瑚粉） | `#FF6F91` | 主要按鈕、自己的訊息泡泡、強調色 |
| 主色深色 | `#E85C7F` | 主色的 hover/active 狀態 |
| 薰衣草紫 | `#845EC2` | 連結文字、系統提示（加入/離開）文字 |
| 紫色底 | `#F3E9FF` | 系統提示文字的底色 |
| 薄荷綠 | `#2EC4B6` | 線上狀態小圓點、在線相關提示 |
| 薄荷綠底 | `#E9F9F6` | 「線上 N 人」按鈕底色 |
| 警示黃底 | `#FFF1CF` | 斷線提示條底色 |
| 警示黃文字 | `#8A6A1F` | 斷線提示條文字 |
| 失敗紅 | `#FF5A5F` | 「傳送失敗」文字 |
| 主要文字 | `#4A3F3B` | 深咖啡色，取代純黑，比較柔和 |
| 次要文字 | `#8C7F7A` | 次要說明文字、代號+時間 |
| 更淡文字 | `#C9B8AE` | placeholder、footnote |
| 輸入框邊框 | `#F0DCC9` | 一般邊框 |
| 一般分隔線 | `#FBEADA` | header、input 區的分隔線 |

頭像底色是從代號文字算出來的固定顏色，在這幾色裡輪流選：`#FF6F91` `#2EC4B6` `#845EC2` `#F9A826` `#4D8076` `#5B8DEF`（同一個代號永遠對應同一個顏色）。

## 3. 字體

- 標題／按鈕文字：**Fredoka**（圓潤、有份量，Google Fonts），粗細用 600~700。
- 一般內文／訊息內容：**Nunito**（友善好讀的無襯線字），粗細 400~800。
- 兩種字體都是免費的 Google Fonts，用 `<link>` 從 `fonts.googleapis.com` 載入即可，不用額外安裝字型檔。

## 4. 圖示規則

- 不用 emoji 當功能圖示（例如上傳圖片、編輯、離開按鈕都不是 emoji）。
- 一律用簡單的線條風格 SVG（stroke，不是實心色塊），顏色跟著文字顏色走（`#8C7F7A` 或 `#B5A89F`），風格統一、裝飾性低。
- 頭像不用大頭照或插畫，用「代號第一個字＋彩色圓底」就好，簡單又有辨識度。

## 5. 版型：兩種寬度，同一套內容

這個網站是「響應式」的（同一份網頁，依瀏覽器寬度自動切換版型），不是手機版、電腦版兩個獨立網站：

- **寬度 ≤ 768px（手機）**：線上名單收起來，變成 header 右邊一個「線上 N 人」的小按鈕，點了從右側滑出一個名單面板。
- **寬度 > 768px（電腦/平板橫向）**：線上名單固定顯示在畫面右側，沒有收合按鈕，隨時看得到。

切換的斷點：`768px`（用 CSS media query 判斷）。

## 6. 畫面 A：輸入代號

一張置中卡片，背景是奶油色到淺橘的直向漸層，卡片後方有兩顆淡色圓形裝飾（左上淺橘、右下淺薄荷綠）增加活潑感。

由上到下：

1. **圖示方塊**：88×88px、圓角 28px、珊瑚粉底，中間放白色對話框線條圖示（像聊天泡泡，裡面三個小圓點）。
2. **標題**「匿名聊天室」：Fredoka、30px、深咖啡色文字，置中。
3. **說明文字**：「不用註冊、不用登入／輸入一個代號，馬上開始聊天」，兩行，14~15px，次要文字色，置中。
4. **代號輸入框**：寬度頂滿卡片內容區（手機上大約 300px 寬上限）、高度約 50px、圓角 16px、白底、2px 邊框（一般是淺橘邊框，focus 時變珊瑚粉並加一圈淡粉色光暈）。placeholder：「輸入你的代號（最多 20 字）」。`maxlength="20"`。
5. **錯誤提示**（預設隱藏）：留空按送出才顯示，紅字、13px、粗體，貼著輸入框下方、靠左對齊：「請先輸入一個代號才能進入聊天室喔！」
6. **「進入聊天室」按鈕**：滿寬、圓角 999px（藥丸形狀）、珊瑚粉底、白字、Fredoka 字體 17px，有柔和的粉色陰影。按下去會有輕微縮小的回饋動畫。
7. **footnote**：「代號可以跟別人重複沒關係，每次重新進來都要再輸入一次喔！」，12px、更淡文字色，置中。

## 7. 畫面 B：聊天室

### 7.1 Header（固定在最上面）

- 左邊：「← 離開」文字按鈕，次要文字色，圖示是線條風格的左箭頭。
- 中間：「匿名聊天室」標題，Fredoka 17~19px，置中。
- 右邊（**只在手機寬度顯示**）：「● 線上 N 人」藥丸按鈕，薄荷綠底、深綠字，點擊展開線上名單面板。電腦寬度時這個位置留空（名單已經固定顯示在右側）。

### 7.2 斷線提示條（平時隱藏）

緊貼在 header 下方，滿版寬度，黃底、深黃字、置中粗體文字：「連線中斷，正在重新連線...」。只有偵測到斷線時才出現，恢復連線後自動消失。

### 7.3 訊息列表

訊息區最大寬度 720px、置中，上下可滾動，訊息之間間距 14px。

- **系統提示**（加入/離開）：置中的小藥丸，紫底紫字：「XX 加入了聊天室」/「XX 離開了聊天室」。
- **一般訊息**：
  - 左右對齊：自己的訊息靠右、頭像在右邊；別人的訊息靠左、頭像在左邊。
  - 頭像：32px 圓形，代號首字＋彩色底。
  - 頭像旁邊是：「代號 · 時間」（11.5px、淡文字色），再往下是訊息泡泡。被編輯過的訊息，這一行文字後面加「· 已編輯」。
  - 泡泡：圓角 16px、padding 約 10×14px、14.5px 字。別人的泡泡是白底深色字；自己的泡泡是珊瑚粉底白字。超過一行會自動換行，保留使用者按 Shift+Enter 換的行。
  - 圖片訊息：圖片本身圓角 16px、有一條淺色邊框，最大寬度約 220px。
  - 自己且還沒超過編輯時限的訊息，泡泡旁邊有一個小小的「鉛筆」線條圖示，點了才出現編輯功能。
  - 編輯中：原本的泡泡變成一個白底、珊瑚粉邊框的方框，裡面是可以打字的文字框，下面兩個藥丸按鈕「取消」（淺咖啡底）和「儲存」（珊瑚粉底）。
  - 傳送失敗：泡泡下方（靠自己這一側對齊）出現紅字按鈕「⚠ 傳送失敗，點擊重試」，點了會重新嘗試送出。
- **「回到底部」按鈕**：使用者往上捲動看歷史、此時有新訊息進來時，列表底部會浮出一個深咖啡底、白字的藥丸按鈕：「有新訊息，點擊回到底部 ↓」。點擊後捲到最新訊息並消失。使用者本來就在底部時，新訊息會直接自動捲動顯示，不出現這個按鈕。

### 7.4 輸入區（固定在最下面）

- 一個圓角 18px 的輸入容器，裡面从左到右：
  - 可多行的文字輸入框（textarea），placeholder：「輸入訊息，Enter 送出、Shift+Enter 換行」，最高大約 110px 後開始內部滾動。
  - 「上傳圖片」圖示按鈕（線條風格的相片圖示）。
  - 送出按鈕：38px 圓形、珊瑚粉底，裡面是白色的紙飛機線條圖示。
  - 拖曳圖片到這個容器上時，外框會變成珊瑚粉色提示「這裡可以放」。
- 輸入框下方有一行小提示文字（11px、更淡文字色）：「也可以直接拖曳圖片，或用 Ctrl+V 貼上剪貼簿裡的圖片」。

### 7.5 線上名單

- **電腦版（固定側欄）**：寬度 260~280px、固定在畫面右側，白底、左邊有分隔線。上方顯示「● 線上 N 人」標題，下面是垂直排列的使用者列表，每行是「彩色圓形頭像＋代號文字」。
- **手機版（收合面板）**：點 header 的「線上 N 人」按鈕後，從右側滑出一個白底面板（寬度約 260px，蓋住畫面右邊部分），上方是「線上名單」標題＋關閉按鈕（✕），下面是同樣的使用者列表。面板外的半透明深色遮罩區域點擊也能關閉面板。

## 8. 無障礙與其他設計原則

- 所有可點擊的元素都是真正的 `<button>` 或 `<a>`，不是加了 onclick 的 `<div>`，確保鍵盤 Tab 和螢幕報讀器可以正常使用。
- 純裝飾用的圖示加 `aria-hidden="true"`；只有圖示、沒有文字的按鈕（例如關閉✕按鈕）要加 `aria-label` 說明功能。
- 文字顏色和底色的對比度都有留意，避免淡色文字疊在淡色底上造成看不清楚。
- 用來區分狀態的顏色（例如之後若要加「成功/失敗」的顏色），也會同時搭配文字或圖形差異，不會只靠顏色區分（紅綠色盲友善）。
